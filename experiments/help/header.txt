Print or set SWF header values.
[1;4mUsage[m: <executable> [PRE-OPTIONS] [1m-header[m \
       [33m-set[m [3m<key>[m [3m<value>[m [[33m-set[m [3m<key2>[m [3m<value2>[m ...] [3m<swffile>[m [[3m<outfile>[m]

[1;4mExecutable[m:
       Linux: ffdec or ffdec.sh
      Mac OS: ffdec.sh
     Windows: ffdec-cli.exe or ffdec.bat
        Java: java -jar ffdec.jar

[1;4mDescription[m:
    Print header or sets SWF header values (with [33m-set[m arguments) in [3m<swffile>[m
    and saves it to [3m<outfile>[m.
    Available keys: version
                    gfx (true/false)
                    displayrect ([x1,y1,x2,y2])
                    width
                    height
                    framecount
                    framerate
    For width, height and displayrect subvalues you can use suffix px for
    pixel values. Otherwise its twips.

[1;4mPre-options[m:
[33m-config[m key=value[,key2=value2][,key3=value3...]
    Set configuration values.
    Use [1m-listconfigs[m command to list the available configuration settings.
    Values are boolean, you can use 0/1, true/false, on/off or yes/no.
    If no other parameters passed, configuration is saved.
    Otherwise it is used only once.
    DO NOT PUT space between comma (,) and next value.

[33m-configFile[m [3m<file>[m
    Use configuration from a file [3m<file>[m. TOML file format is expected.
    When it has .bin extension, legacy storage is used.

[33m-charset[m [3m<charsetName>[m
    Set desired character set for reading/writing SWF files with
    SWF version <= 5.

[33m-tagProfile[m [3m<profileId>[m
    Use a tag profile when reading SWF files.
    Use "standard" for standard SWF tag interpretation.
    Use [33m-listtagprofiles[m to list available profile identifiers.


[4;1mExamples[m:
ffdec -header myfile.swf
ffdec -header -set version 10 -set width 800px -set framerate 23.5 myfile.swf outfile.swf
ffdec -header -set displayrect [0,0,800px,600px] myfile.swf outfile.swf
ffdec -header -set gfx true myfile.swf outfile.swf

You can use special value "/dev/stdin" for input files to read data 
from standard input (even on Windows)
